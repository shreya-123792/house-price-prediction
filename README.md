🏠 House Price Prediction using Machine Learning
📌 Project Overview

This project predicts house prices using Machine Learning based on various house features such as bedrooms, bathrooms, living area, grade, condition, location, and more.

A user-friendly Streamlit web application allows users to enter house details and receive an estimated house price in both USD and Indian Rupees (INR).

🚀 Features
Predict house prices using an XGBoost Regression model
Interactive Streamlit web application
Displays predicted price in USD and INR
Clean and user-friendly interface
Machine Learning model trained on real estate data
Responsive input form with multiple house features
